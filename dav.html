Anthology WebDAV Arka Planda Nasıl Çalışır?

Go (Golang) ile sıfırdan yazılmış yüksek performanslı eşzamanlı (concurrency) motoru sayesinde her şey saniyeler içinde RAM üzerinde gerçekleşir.

1
Kütüphaneye Ekleme
Kullanıcı web arayüzünden veya Finder içinden bir film/dizi seçer. TMDB verileri önbelleklenir ve sanal dizine işlenir.
→
2
Sanal Dosya Sistemi
VFS, diske 0 bayt video yazarak RAM üzerinde .strm işaretçi dosyalarını oluşturur (Örn: Breaking Bad - S01E01.strm).
→
3
Medya Oynatıcı Talebi
Infuse, Kodi veya VLC bölüme tıkladığında /stream/resolve adresine istek atar. Sunucu uyanır.
→
4
34 Paralel Çözücü
Motor, kategorideki tüm siteleri aynı anda tarar; Vidrame XOR, Vidmoxy ROT13, CloseLoad ve token korumalarını deşifre eder.
→
5
HTTP 206 Akış Köprüsü
En yüksek kaliteli 1080p/4K akış seçilir. Range header ve HLS segmentleri proxy edilerek kesintisiz oynatılır.

Hangi Cihazda Nasıl Kullanılır?

Anthology WebDAV evrensel HTTP ve WebDAV standartlarını destekler. Ev ağınızdaki tüm cihazları dakikalar içinde sinema merkezine dönüştürün:

💻
macOS
MacBook, iMac, Mac mini/Studio
Infuse (Tavsiye) VidHub IINA Finder ⌘K VLC

    Infuse veya VidHub'ı açın: Ayarlar ⚙️ → Paylaşımlar → Paylaşım Ekle → WebDAV (HTTP) seçin.
  • 2
    Bağlantı Bilgileri: Adres: 127.0.0.1 *(veya canlı sunucu için: anthology-dav.duckdns.org, Port: 443, HTTPS)*, Yol: /dav. Kullanıcı adı/şifre: Yerelde boş bırakın; canlı sunucuda web panelinde açtığınız hesabınızı girin.
  • 3
    Finder'a Disk Olarak Bağlama: Finder'dayken ⌘K tuşlarına basıp http://127.0.0.1:8085/dav/ yazın ve "Konuk" olarak bağlanın.

🌐 Ev Ağında (LAN) ve Dışarıdan (Uzaktan) Erişim Mimarisi

Sunucuyu sadece kendi bilgisayarınızda değil; evdeki akıllı televizyondan veya seyahatteyken telefonunuzdan kullanmak için 2 kolay yöntem vardır:

☁️ 1. Canlı Sunucu (Çok Kullanıcılı)

Herhangi bir kurulum yapmadan doğrudan çevrim içi hesabınızı açıp bağlanın: 

https://anthology-dav.duckdns.org
  • • Web Girişi: Tarayıcıdan açıp saniyeler içinde hesap oluşturun veya giriş yapın.
  • • İzole Kütüphane: Eklediğiniz tüm dizi ve filmler yalnızca size özel tutulur.
  • • WebDAV Bağlantısı: Infuse / Kodi'ye adres olarak anthology-dav.duckdns.org, port 443 (HTTPS), kullanıcı adı ve şifrenizle bağlanın.

🏠 2. Yerel Ev Ağı (Aynı Wi-Fi)

Kendi bilgisayarınızda çalıştırırken tüm yerel cihazları dinleyin: 

./anthology-dav -host 0.0.0.0 -port 8085
  • • Mac IP Bulma: ipconfig getifaddr en0 (Örn: 192.168.1.45)
  • • Windows IP: ipconfig (IPv4 adresi)
  • • TV ve telefonunuzdaki WebDAV adresine http://192.168.1.45:8085/dav yazın.

✈️ 3. Dışarıdan Erişim (Tailscale)

Port açma veya statik IP derdi olmadan güvenli şekilde dışarıdan bağlanın:

  • • Bilgisayarınıza ve telefonunuza ücretsiz Tailscale kurun.
  • • Tailscale'in size verdiği 100.x.y.z IP adresini not edin.
  • • Dışarıdayken Infuse'a http://100.x.y.z:8085/dav adresiyle bağlanarak evdeki sunucunuza güvenle erişin!
⚙️ Kurulum & Arka Plan Servisi

Adım Adım Kurulum Rehberi

Tek bir Go binary dosyası olarak derlenir. Veritabanı veya karmaşık harici bağımlılıklar gerekmez.

1
Gereksinimlerin Hazırlanması (Homebrew)
Derleme araçları ve Go çalışma ortamını Terminal'den tek komutla kurun:
Terminal (Zsh / Bash) 
brew install go git make
2
Projeyi İndirme & Yerel Binary Derleme
Depoyu klonlayın ve Apple Silicon (M1/M2/M3/M4) veya Intel için optimize derleyin:
Terminal Komutları 
# Depoyu klonlayın ve klasöre girin
git clone https://github.com/falsisdev/anthology-dav.git
cd anthology-dav

# Optimize binary derleyin ve macOS izinlerini açın
make build
chmod +x anthology-dav
xattr -cr anthology-dav 2>/dev/null || true
3
Arka Planda Sessizce Başlatma (LaunchAgent Servisi)
Mac'inizi her açtığınızda arka planda sessizce RAM'de çalışması için servisi kurun:
Servis Kurulumu 
make install-service
4
Doğrulama & Canlı Servis Yönetimi
Tarayıcınızda http://localhost:8085/ açarak arayüze erişin. Aşağıdaki pratik yönetim komutlarını kullanabilirsiniz:
📊 Canlı Logları İzle
make logs
🟢 Servis Durumu
make status
🔄 Yeniden Başlat
make restart
🛑 Servisi Kaldır
make uninstall-service
1
Winget ile Go & Git Kurulumu
PowerShell'i Yönetici olarak açın ve araçları yükleyin:
PowerShell (Yönetici) 
winget install GoLang.Go Git.Git
2
Projeyi İndirme & Derleme
Depoyu klonlayıp tek bir anthology-dav.exe dosyası olarak derleyin:
PowerShell Komutları 
git clone https://github.com/falsisdev/anthology-dav.git C:\anthology-dav
cd C:\anthology-dav
go build -o anthology-dav.exe .
3
Siyah Komut Penceresi Açılmadan Başlatma (VBS Script)
Windows açılışında arka planda görünmez olarak başlaması için Başlangıç klasörüne kısayol ekleyin:
  1. Win + R tuşlarına basıp shell:startup yazarak Başlangıç klasörünü açın.
  2. Burada anthology_baslat.vbs adında bir dosya oluşturup aşağıdaki kodu kaydedin:
anthology_baslat.vbs 
Set WshShell = CreateObject("WScript.Shell")
WshShell.CurrentDirectory = "C:\anthology-dav"
WshShell.Run "C:\anthology-dav\anthology-dav.exe -host 0.0.0.0 -port 8085", 0, False

Paket Yöneticisi ile Kurulum
Ubuntu / Debian / Raspberry Pi OS üzerinde gerekli paketleri kurun:
Bash 
sudo apt update && sudo apt install -y golang git make
2
Derleme
Depoyu klonlayıp çalıştırılabilir binary dosyayı derleyin:
Bash 
git clone https://github.com/falsisdev/anthology-dav.git ~/anthology-dav
cd ~/anthology-dav && make build
3
Systemd Kullanıcı Servisi Oluşturma (Root Yetkisi Gerekmez)
Kullanıcı oturumunda otomatik başlatılacak systemd birimini tanımlayın:
Bash 
mkdir -p ~/.config/systemd/user
cat << 'EOF' > ~/.config/systemd/user/anthology-dav.service
[Unit]
Description=Anthology WebDAV Media Server
After=network-online.target

[Service]
WorkingDirectory=%h/anthology-dav
ExecStart=%h/anthology-dav/anthology-dav -host 0.0.0.0 -port 8085
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now anthology-dav.service
4
Canlı Log Takibi
Servisin durumunu ve anlık istek kayıtlarını takip edin:
Bash 
journalctl --user -u anthology-dav.service -f
1
docker-compose.yml Dosyasını Hazırlama
Sunucunuzda veya NAS cihazınızda izole Docker ortamı kurun:
docker-compose.yml 
version: '3.8'

services:
  anthology-dav:
    image: golang:1.24-alpine
    container_name: anthology-dav
    working_dir: /app
    volumes:
      - ./anthology-data:/app
    ports:
      - "8085:8085"
    command: >
      sh -c "apk add --no-cache git make &&
             if [ ! -f main.go ]; then git clone https://github.com/falsisdev/anthology-dav.git . ; fi &&
             go run . -host 0.0.0.0 -port 8085"
    restart: unless-stopped

⚡ Uzman İpuçları & Çevrimdışı İndirme

Deneyimi En Üst Seviyeye Çıkarın

Medya oynatıcılarınızı 10 kat hızlandıracak ayarlar, klavye kısayolları ve seyahatler için gerçek video indirme rehberi:

✈️ Çevrimdışı İndirme Rehberi (Uçak & Seyahat Modu)
WebDAV üzerindeki .strm dosyası sadece 120 baytlık bir yönlendiricidir; içinde fiziksel video barındırmaz. Uçakta veya internetin çekmediği yazlık/seyahat ortamlarında sinema keyfi yaşamak için, yola çıkmadan önce gerçek videoyu doğrudan MP4 olarak cihazınıza indirmeniz gerekir. Anthology WebDAV'ın dahili /stream/resolve uç noktası bunu sizin için otomatikleştirir.
📱 1. Infuse / VidHub ile Tek Tıkla
En Pratik (Mobil / iPad / Mac)
iPhone, iPad veya Mac'inizde Infuse veya VidHub açıkken ilgili film veya bölüm sayfasına girin. "İndir (⬇️)" butonuna basın. Oynatıcı, Anthology WebDAV köprüsünden videoyu doğrudan cihaz hafızasına kaydeder. Uçak modunda sıfır internetle izleyin!
⚡ 2. yt-dlp ile Yüksek Hızlı MP4 İndirme
Çok Parçalı (Maks Hız)
Terminal üzerinden 8 paralel iş parçacığıyla (-N 8) filmi doğrudan 1080p MP4 olarak bilgisayarınıza kaydedin:
Tek Satır Komut 
yt-dlp -N 8 "http://127.0.0.1:8085/stream/resolve?type=movie&tmdb_id=27205&title=Inception&year=2010" -o "Inception_2010.mp4"
🔁 3. Tüm Sezonu Otomatik İndirme Scripti
Diziler & Animeler
12 bölümlük bir anime veya dizi sezonunun tamamını tek tıkla arka arkaya MP4 olarak indiren döngü betiği:
Bash / Zsh Döngüsü 
for ep in {1..12}; do
  yt-dlp -N 8 "http://127.0.0.1:8085/stream/resolve?type=anime&tmdb_id=127532&title=Solo+Leveling&year=2024&season=1&episode=${ep}" \
    -o "Solo_Leveling_S01E$(printf %02d $ep).mp4"
done
🌐 4. Web Arayüzünden & IDM ile İndirme
Tarayıcı Dostu
http://localhost:8085/ web kontrol panelinde kütüphanenizdeki bir filmin yanındaki "Kaynakları Gör" butonuna basın. Listelenen çalışan doğrudan MP4/HLS bağlantısını tarayıcınızdan veya Free Download Manager / IDM'e yapıştırarak indirin.
🎒 Uçuş Öncesi Seyahat Kontrol Listesi
✓ İndirdiğiniz videonun ilk 10 saniyesini çevrimdışı oynatarak doğrulayın.
✓ Yabancı yapımlarda Türkçe altyazı dosyasının (.vtt) indiğini kontrol edin.
✓ Cihazınızda VLC, Infuse veya IINA gibi donanım ivmeli bir medya oynatıcı bulundurun.
✓ Batarya tasarrufu için oynatıcınızda donanım çözücüyü (Hardware Decoding) etkinleştirin.

❓ Sıkça Sorulan Sorular

Aklınıza Takılabilecek Her Şey

Anthology WebDAV hakkında en sık karşılaşılan sorular ve detaylı teknik çözümleri:

1. Öncelikle http://localhost:8085/ adresine girip Kütüphanem sekmesini açın.
2. İçeriğin yanındaki "🔍 Çalışan Kaynakları Bul" butonuna basın. Açılan pencerede hangi sitelerin videoyu anında çözdüğü (HTTP 200) listelenir.
3. Varsayılan "Otomatik Çözücü" yerine açılır menüden çalışan belirli bir sağlayıcıyı (örneğin HDFilmCehennemi veya FilmModu) seçip tekrar oynatmayı deneyin.
4. İnternet servis sağlayıcınızın siteleri DNS seviyesinde engellemediğinden emin olun (Cloudflare 1.1.1.1 veya AdGuard DNS önerilir).
Medya oynatıcılar (özellikle Infuse ve VidHub) klasör listesini yerel hafızasında tutabilir. Oynatıcı içinde ilgili klasörün (Filmler veya Diziler) içine girip yukarıdan aşağıya doğru ekranı kaydırarak Yenile (Refresh / ↻) yapın. Yeni içerik saniyesinde belirecektir.
Arka planda zaten çalışan bir anthology-dav süreci vardır. Mevcut süreci görmek için terminale lsof -i :8085 yazabilirsiniz. Farklı bir portta çalıştırmak isterseniz ./anthology-dav -port 8090 komutunu kullanabilirsiniz.
Sağlayıcıların pek çoğunda Türkçe dublaj veya altyazı videonun içine gömülü (hardsub/çift ses) olarak gelir. Harici .vtt veya .srt sunan sitelerde sunucu altyazıları otomatik olarak çeker. Ayrıca Infuse ve Kodi dosya adını uluslararası standartta gördüğü için tek tıkla OpenSubtitles üzerinden Türkçe altyazı indirebilir.
Televizyonunuz 127.0.0.1 adresini kendi içine arayacağı için videoyu bulamaz. Çözüm çok basittir: Sunucuyu başlatırken -public-url http://192.168.1.X:8085 parametresini verin veya WebDAV istemcinizde adrese bilgisayarınızın yerel IP'sini yazın.
Kesinlikle hayır! Anthology WebDAV derlenmiş yerel Go kodudur. Boşta yaklaşık 35 MB RAM harcar ve %0 CPU tüketir. Ağır video transcode işlemi yapmaz; videoları doğrudan donanım hızlandırmalı olarak oynatıcıya köprüler.
Evet, bilgisayar tamamen derin uykuya geçerse ağ bağlantısı kopar. Bunu önlemek için macOS Sistem Ayarları'ndan "Ağ erişimi için uyandır" seçeneğini açabilir veya ücretsiz Amphetamine uygulamasıyla sunucu çalışırken Mac'inizin uyanık kalmasını sağlayabilirsiniz.
Kütüphanenizdeki tüm içerikler ve sağlayıcı tercihleriniz yalnızca library.json dosyasında tutulur. Bu dosyayı yedeklemeniz tüm koleksiyonunuzu korumak için yeterlidir!

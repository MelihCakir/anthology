🧠 Teknik Mimari

Anthology WebDAV Arka Planda Nasıl Çalışır?

Go (Golang) ile sıfırdan yazılmış yüksek performanslı eşzamanlı (concurrency) motoru sayesinde her şey saniyeler içinde RAM üzerinde gerçekleşir.

1
Kütüphaneye Ekleme
Kullanıcı web arayüzünden veya Finder içinden bir film/dizi seçer. TMDB verileri önbelleklenir ve sanal dizine işlenir.
→
2
Sanal Dosya Sistemi
VFS, diske 0 bayt video yazarak RAM üzerinde .strm işaretçi dosyalarını oluşturur (Örn: Breaking Bad - S01E01.strm).
→
3
Medya Oynatıcı Talebi
Infuse, Kodi veya VLC bölüme tıkladığında /stream/resolve adresine istek atar. Sunucu uyanır.
→
4
34 Paralel Çözücü
Motor, kategorideki tüm siteleri aynı anda tarar; Vidrame XOR, Vidmoxy ROT13, CloseLoad ve token korumalarını deşifre eder.
→
5
HTTP 206 Akış Köprüsü
En yüksek kaliteli 1080p/4K akış seçilir. Range header ve HLS segmentleri proxy edilerek kesintisiz oynatılır.

🌐 Ev Ağında (LAN) ve Dışarıdan (Uzaktan) Erişim Mimarisi

Sunucuyu sadece kendi bilgisayarınızda değil; evdeki akıllı televizyondan veya seyahatteyken telefonunuzdan kullanmak için 2 kolay yöntem vardır:

🏠 1. Ev Ağı (Aynı Wi-Fi) Erişimi

Sunucuyu tüm yerel ağ kartlarını dinleyecek şekilde başlatın: 

./anthology-dav -host 0.0.0.0 -port 8085
  • • Mac IP Bulma: ipconfig getifaddr en0 (Örn: 192.168.1.45)
  • • Windows IP Bulma: ipconfig (IPv4 adresi)
  • • TV ve telefonunuzdaki WebDAV adresine http://192.168.1.45:8085/dav yazın.

✈️ 2. Dışarıdan Erişim (Tailscale / VPN)

Port açma veya statik IP derdi olmadan güvenli şekilde dışarıdan bağlanın:

  • • Bilgisayarınıza ve telefonunuza ücretsiz Tailscale (veya WireGuard) kurun.
  • • Tailscale'in size verdiği 100.x.y.z IP adresini not edin.
  • • Dışarıdayken (mobil veri veya otel Wi-Fi) Infuse'a http://100.x.y.z:8085/dav adresiyle bağlanarak evdeki sunucunuza güvenle erişin!
⚙️ Kurulum & Arka Plan Servisi

Adım Adım Kurulum Rehberi

Tek bir Go binary dosyası olarak derlenir. Veritabanı veya karmaşık bağımlılıklar gerekmez.

🍎 macOS Üzerinde Kurulum ve Arka Plan Servisi (LaunchAgent)

Terminal Komutları 
# 1. Ön Gereksinimler (Homebrew ile Go ve Git kurulumu)
brew install go git make

# 2. Projeyi GitHub'dan indirin ve klasöre girin
git clone https://github.com/falsisdev/anthology-dav.git
cd anthology-dav

# 3. Derleyin ve çalıştırma izni verin
make build
chmod +x anthology-dav
xattr -cr anthology-dav 2>/dev/null || true

# 4. Bilgisayar açıldığında arka planda sessizce başlaması için servisi kurun:
make install-service
📊 Canlı Logları İzlemek İçin:
make logs (veya tail -f /tmp/anthology-dav.log)
🛑 Servisi Durdurup Kaldırmak İçin:
make uninstall-service

🪟 Windows 10 & 11 Kurulumu ve Başlangıçta Otomatik Açılma

PowerShell (Yönetici) 
# 1. Go ve Git'i Winget ile kurun
winget install GoLang.Go Git.Git

# 2. Projeyi klonlayın ve derleyin
git clone https://github.com/falsisdev/anthology-dav.git C:\anthology-dav
cd C:\anthology-dav
go build -o anthology-dav.exe .

Siyah Komut Penceresi Açılmadan Arka Planda Başlatma (VBS Script):

  1. Win + R tuşlarına basıp shell:startup yazarak Başlangıç klasörünü açın.
  2. Burada anthology_baslat.vbs adında bir dosya oluşturun ve içine şunu yapıştırın:
anthology_baslat.vbs 
Set WshShell = CreateObject("WScript.Shell")
WshShell.CurrentDirectory = "C:\anthology-dav"
WshShell.Run "C:\anthology-dav\anthology-dav.exe -host 0.0.0.0 -port 8085", 0, False

🐧 Linux Üzerinde Systemd Kullanıcı Servisi Kurulumu

Bash 
# 1. Derleme araçlarını yükleyin
sudo apt update && sudo apt install -y golang git make

# 2. Projeyi derleyin
git clone https://github.com/falsisdev/anthology-dav.git ~/anthology-dav
cd ~/anthology-dav && make build

# 3. Systemd servis dosyasını oluşturun (~/.config/systemd/user/anthology-dav.service)
mkdir -p ~/.config/systemd/user
cat << 'EOF' > ~/.config/systemd/user/anthology-dav.service
[Unit]
Description=Anthology WebDAV Media Server
After=network-online.target

[Service]
WorkingDirectory=%h/anthology-dav
ExecStart=%h/anthology-dav/anthology-dav -host 0.0.0.0 -port 8085
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
EOF

# 4. Servisi etkinleştirin ve başlatın
systemctl --user daemon-reload
systemctl --user enable --now anthology-dav.service

⚡ Uzman İpuçları & Çevrimdışı İndirme

Deneyimi En Üst Seviyeye Çıkarın

Medya oynatıcılarınızı 10 kat hızlandıracak ayarlar, klavye kısayolları ve seyahatler için gerçek video indirme rehberi:

HAYATİ AYAR

🚀 10 Kat Daha Hızlı Poster Yükleme

Infuse, VidHub veya Kodi'de "Gömülü Metaveri" (Embedded Metadata) ayarı açıksa, oynatıcı her bir bölümün codec bilgisini almak için video içine girip sağlayıcılara yüzlerce istek atar ve tarama kilitlenir!

✅ Infuse Ayarı: Ayarlar → Genel → Gömülü Metaveri: KAPALI
✅ Detay Ön-Önbellekleme: KAPALI

📁 MKCOL Hilesi (Klasör Açarak Arama)

Tarayıcıyı hiç açmadan doğrudan Finder veya Dosya Gezgini içinden arama yapabilirsiniz:

1. /dav/Watchlist/ klasörüne girin.
2. Yeni Klasör Oluştur (⌘+Shift+N) deyin ve klasörün adını aramak istediğiniz içerik yapın (Örn: Kurtlar Vadisi).
3. Sunucu saniyeler içinde o klasörün içini bölümlerle dolduracaktır!

💾 Çevrimdışı İndirme Rehberi (Uçak & Seyahat Modu)

WebDAV'daki .strm dosyası sadece 120 baytlık bir yönlendirme adresidir. Gerçek videoyu bilgisayarınıza MP4 veya MKV olarak indirmek için yt-dlp veya ffmpeg kullanabilirsiniz:

Terminal Komutları (yt-dlp ile Doğrudan 1080p İndirme) 
# Tek bir filmi veya bölümü en yüksek kalitede MP4 olarak indirmek için:
yt-dlp "http://127.0.0.1:8085/stream/resolve?type=movie&tmdb_id=27205&title=Inception&year=2010" -o "Inception_2010.mp4"

# Tüm sezonu tek komutla sırayla MP4 olarak indirmek için Bash döngüsü:
for ep in {1..12}; do
  yt-dlp "http://127.0.0.1:8085/stream/resolve?type=anime&tmdb_id=127532&title=Solo+Leveling&year=2024&season=1&episode=${ep}" \
    -o "Solo_Leveling_S01E$(printf %02d $ep).mp4"

Aklınıza Takılabilecek Her Şey

Anthology WebDAV hakkında en sık karşılaşılan sorular ve detaylı teknik çözümleri:

1. Öncelikle http://localhost:8085/ adresine girip Kütüphanem sekmesini açın.
2. İçeriğin yanındaki "🔍 Çalışan Kaynakları Bul" butonuna basın. Açılan pencerede hangi sitelerin videoyu anında çözdüğü (HTTP 200) listelenir.
3. Varsayılan "Otomatik Çözücü" yerine açılır menüden çalışan belirli bir sağlayıcıyı (örneğin HDFilmCehennemi veya FilmModu) seçip tekrar oynatmayı deneyin.
4. İnternet servis sağlayıcınızın siteleri DNS seviyesinde engellemediğinden emin olun (Cloudflare 1.1.1.1 veya AdGuard DNS önerilir).
Medya oynatıcılar (özellikle Infuse ve VidHub) klasör listesini yerel hafızasında tutabilir. Oynatıcı içinde ilgili klasörün (Filmler veya Diziler) içine girip yukarıdan aşağıya doğru ekranı kaydırarak Yenile (Refresh / ↻) yapın. Yeni içerik saniyesinde belirecektir.
Arka planda zaten çalışan bir anthology-dav süreci vardır. Mevcut süreci görmek için terminale lsof -i :8085 yazabilirsiniz. Farklı bir portta çalıştırmak isterseniz ./anthology-dav -port 8090 komutunu kullanabilirsiniz.
Sağlayıcıların pek çoğunda Türkçe dublaj veya altyazı videonun içine gömülü (hardsub/çift ses) olarak gelir. Harici .vtt veya .srt sunan sitelerde sunucu altyazıları otomatik olarak çeker. Ayrıca Infuse ve Kodi dosya adını uluslararası standartta gördüğü için tek tıkla OpenSubtitles üzerinden Türkçe altyazı indirebilir.
Televizyonunuz 127.0.0.1 adresini kendi içine arayacağı için videoyu bulamaz. Çözüm çok basittir: Sunucuyu başlatırken -public-url http://192.168.1.X:8085 parametresini verin veya WebDAV istemcinizde adrese bilgisayarınızın yerel IP'sini yazın.
Kesinlikle hayır! Anthology WebDAV derlenmiş yerel Go kodudur. Boşta yaklaşık 35 MB RAM harcar ve %0 CPU tüketir. Ağır video transcode işlemi yapmaz; videoları doğrudan donanım hızlandırmalı olarak oynatıcıya köprüler.
Evet, bilgisayar tamamen derin uykuya geçerse ağ bağlantısı kopar. Bunu önlemek için macOS Sistem Ayarları'ndan "Ağ erişimi için uyandır" seçeneğini açabilir veya ücretsiz Amphetamine uygulamasıyla sunucu çalışırken Mac'inizin uyanık kalmasını sağlayabilirsiniz.
Kütüphanenizdeki tüm içerikler ve sağlayıcı tercihleriniz yalnızca library.json dosyasında tutulur. Bu dosyayı yedeklemeniz tüm koleksiyonunuzu korumak için yeterlidir!
